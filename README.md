## ✨ About / О моде

**EN:** Yeta brings selected Minecraft Bedrock behaviors to Java Edition: armor-stand poses, potion cauldrons, snow physics and weathering, refreshed visuals, smarter hostile mobs and enhanced chat.

**RU:** Yeta переносит отдельные механики Minecraft Bedrock в Java Edition: позы стоек, зелья в котлах, поведение снега, улучшения мобов, визуальные эффекты и оформление чата.

**Status / Статус:** Experimental · Тестовая версия. Some features have not yet been fully verified against Bedrock in live gameplay.

## 📦 Install / Установка

Download a JAR from [GitHub Releases](https://github.com/Ketsuneban/Yeta/releases), install Minecraft **1.21.1** with **NeoForge 21.1.x**, and place the JAR into `.minecraft/mods/`. Multiplayer gameplay mechanics require installation on the server too.

Скачайте JAR из раздела релизов, установите NeoForge для Minecraft 1.21.1 и переместите файл в папку `mods`. Для серверных механик мод необходим также на сервере.

## 🧰 Build / Сборка

```sh
gradle --no-daemon clean build
```

Java 21 and Gradle 8.14.3 are used by GitHub Actions. Source is MIT licensed.
