# Vectora SVG — самостоятельный векторный редактор для Android

**Версия 0.4.1 (предварительная)** · Android 8+ · автономный APK · работает без ibisPaint и без интернета.

Это **полноценное самостоятельное приложение**, а не дополнение или плавающее окно ibisPaint X. Программа использует собственный полноэкранный холст на Android WebView, но **хранит и сохраняет рисунки в SVG**.

## Основные возможности

- **Импорт SVG поверх текущего рисунка:** кнопка **⊕ Наложить SVG** вставляет другой файл в отдельной векторной группе поверх существующего холста. Импорт не заменяет текущий рисунок.
- **Пропорциональное масштабирование SVG:** выдели импортированную группу и перемещай её пальцем, масштабируй двумя пальцами либо ползунком **Масштаб** (5–1000% от исходного размера вставки). Ширина и высота изменяются одним коэффициентом без растяжения.
- **Неограниченный по дизайну повторный импорт:** можно добавлять несколько SVG по одному, сохраняя внутренние формы, тексты и поддерживаемые градиенты; практический размер итогового документа ограничен **8 МиБ**, а сложные эффекты могут поддерживаться частично.
- **Векторная кисть:** рисование пальцем/стилусом, сглаженные SVG-контуры `<path>`, цвет, толщина, прозрачность.
- **Полноценная заливка связной области:** отображаем SVG на временный скрытый холст только для вычисления границ; выполняем 4-связную flood fill по цветам пикселей с настраиваемым допуском; трассируем границы области и отверстий в замкнутые **векторные** `<path fill-rule="evenodd">`. В итоговом SVG нет внедрённого растра для заливки.
- **Пипетка:** берёт итоговый отображаемый цвет и альфа-канал в точке касания.
- **Выбор цвета:** системный HTML color picker, поле HEX (включая `#RRGGBBAA`), палитра цветов и ползунок прозрачности.
- **Векторный ластик:** скрывает части рисунка SVG-маской с чёрными штрихами, без растрирования исходных объектов.
- Фигуры: прямоугольник, эллипс, линия, текст; выбор, перетаскивание, изменение цвета, удаление.
- Undo/redo до 30 состояний; локальное автосохранение.
- Открытие и сохранение `.svg` через системный файловый диалог Android. Объединённый документ сохраняется в **один SVG**, при этом импортированные объекты остаются вложенными SVG-группами, а не PNG.
- Дополнительный экспорт PNG с прозрачностью.

## Как работает векторная заливка

Заливка вычисляет связную область по рендеру SVG с максимальной стороной 1500 пикселей и ограничением 1,75 млн пикселей. Алгоритм:
1. Считывает цвет, включая альфа-канал, в точке касания.
2. Находит соседние пиксели похожего цвета с настраиваемым допуском, ограниченные контуром.
3. Строит граничные рёбра области, включая внутренние отверстия.
4. Преобразует границы в настоящую геометрию SVG (без bitmap).

**Особенности и ограничения:** это цветовая заливка видимой области, а не математическое булево объединение векторных фигур. Качество границы зависит от разрешения обнаружения; на очень тонких/незамкнутых линиях могут возникать протечки, поэтому можно регулировать допуск. Контуры после трассировки могут содержать много углов/вершин. Сложные SVG (особенно внешние ресурсы и скрипты) намеренно очищаются от опасных элементов. Маски и локальные фильтры поддерживаются частично. Полноценного редактора узлов Безье и векторных слоёв пока нет.

## Установка

1. Открой GitHub Release **vectora-svg-v0.4.1** после успешной автоматической сборки.
2. Скачай `vectora-svg-v0.4.1-debug.apk` и установи вручную.
3. Запусти **Vectora SVG**, выбери `Новый` или `Открыть`.
4. Рисуй кистью, нажимай по областям инструментом **Заливка**, бери цвет **Пипеткой**.
5. Нажми **⊕ Наложить SVG**, выбери ещё один SVG. Он появится по центру поверх текущего рисунка. Перетаскивай импортированную группу, сжимай или раздвигай два пальца, либо меняй масштаб ползунком. Повтори для других файлов.
6. **SVG ↓** сохраняет объединённый векторный файл, **PNG ↓** создаёт дополнительный растровый файл.

Приложение имеет отдельный ID `dev.ketsuneban.vectora`: ставится отдельно от прежнего SVG Bridge. **Никаких разрешений на показ поверх других приложений, сетевого доступа и специальных разрешений не запрашивает.** В Release публикуется отладочная сборка, не предназначенная для магазина приложений.

## Сборка

Нужны JDK 17, Android SDK 35, Gradle 8.9.

```sh
cd ibis-svg-bridge
gradle --no-daemon assembleDebug
```

Путь сборки: `app/build/outputs/apk/debug/app-debug.apk`.

Границы заливки тестируются отдельно:

```sh
node --test tests/floodfill.test.cjs tests/vector-overlay.test.cjs tests/vector-layers.test.cjs
```

## Совместимость SVG при наложении

Импортированный SVG вставляется внутрь вложенного `<svg>` в `<g transform="translate(...) scale(...)" data-vectora-overlay="true">`. Размер меняется **единым коэффициентом**: нет независимого изменения ширины/высоты, поэтому рисунок не искажается. При каждом импорте локальные `id` и ссылки вида `url(#id)` / `href="#id"` переименовываются, чтобы SVG со схожими градиентами и фильтрами не конфликтовали. Поддерживаемые формы, шрифтовые элементы, градиенты и маски остаются в SVG.

В целях безопасности активные скрипты, удалённые ресурсы, встроенные изображения и неподдерживаемые конструкции отфильтровываются при импорте, поэтому сложный SVG может частично изменить вид. Переименованные элементы сохраняются при повторном открытии итогового SVG. Масштаб и положение группы восстанавливаются из собственных атрибутов проекта.

## Исправление слоя ластика в v0.4.1

Импортированные SVG-группы теперь всегда выводятся **поверх основного рисунка и маски ластика**. Стирание не затрагивает наложенный SVG. Если открыть сохранённый документ из v0.4.0, редактор автоматически переносит импортированные группы из-под маски в верхний слой, не изменяя их геометрию, трансформации и размеры. После открытия старого файла сохрани его заново, чтобы зафиксировать исправленную структуру. Кисть и ластик относятся к основному слою; импортированные SVG остаются над ним.
