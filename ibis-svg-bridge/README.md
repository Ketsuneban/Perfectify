# Vectora SVG — самостоятельный векторный редактор для Android

**Версия 0.3.0 (предварительная)** · Android 8+ · автономный APK · работает без ibisPaint и без интернета.

Это **полноценное самостоятельное приложение**, а не дополнение или плавающее окно ibisPaint X. Программа использует собственный полноэкранный холст на Android WebView, но **хранит и сохраняет рисунки в SVG**.

## Основные возможности

- **Векторная кисть:** рисование пальцем/стилусом, сглаженные SVG-контуры `<path>`, цвет, толщина, прозрачность.
- **Полноценная заливка связной области:** отображаем SVG на временный скрытый холст только для вычисления границ; выполняем 4-связную flood fill по цветам пикселей с настраиваемым допуском; трассируем границы области и отверстий в замкнутые **векторные** `<path fill-rule="evenodd">`. В итоговом SVG нет внедрённого растра для заливки.
- **Пипетка:** берёт итоговый отображаемый цвет и альфа-канал в точке касания.
- **Выбор цвета:** системный HTML color picker, поле HEX (включая `#RRGGBBAA`), палитра цветов и ползунок прозрачности.
- **Векторный ластик:** скрывает части рисунка SVG-маской с чёрными штрихами, без растрирования исходных объектов.
- Фигуры: прямоугольник, эллипс, линия, текст; выбор, перетаскивание, изменение цвета, удаление.
- Undo/redo до 30 состояний; локальное автосохранение.
- Открытие и сохранение `.svg` через системный файловый диалог Android.
- Дополнительный экспорт PNG с прозрачностью.

## Как работает векторная заливка

Заливка вычисляет связную область по рендеру SVG с максимальной стороной 1500 пикселей и ограничением 1,75 млн пикселей. Алгоритм:
1. Считывает цвет, включая альфа-канал, в точке касания.
2. Находит соседние пиксели похожего цвета с настраиваемым допуском, ограниченные контуром.
3. Строит граничные рёбра области, включая внутренние отверстия.
4. Преобразует границы в настоящую геометрию SVG (без bitmap).

**Особенности и ограничения:** это цветовая заливка видимой области, а не математическое булево объединение векторных фигур. Качество границы зависит от разрешения обнаружения; на очень тонких/незамкнутых линиях могут возникать протечки, поэтому можно регулировать допуск. Контуры после трассировки могут содержать много углов/вершин. Сложные SVG (особенно внешние ресурсы и скрипты) намеренно очищаются от опасных элементов. Маски и локальные фильтры поддерживаются частично. Полноценного редактора узлов Безье и векторных слоёв пока нет.

## Установка

1. Открой GitHub Release **vectora-svg-v0.3.0** после успешной автоматической сборки.
2. Скачай `vectora-svg-v0.3.0-debug.apk` и установи вручную.
3. Запусти **Vectora SVG**, выбери `Новый` или `Открыть`.
4. Рисуй кистью, нажимай по областям инструментом **Заливка**, бери цвет **Пипеткой**.
5. **SVG ↓** сохраняет векторный файл, **PNG ↓** создаёт дополнительный растровый файл.

Приложение имеет отдельный ID `dev.ketsuneban.vectora`: ставится отдельно от прежнего SVG Bridge. **Никаких разрешений на показ поверх других приложений, сетевого доступа и специальных разрешений не запрашивает.** В Release публикуется отладочная сборка, не предназначенная для магазина приложений.

## Сборка

Нужны JDK 17, Android SDK 35, Gradle 8.9.

```sh
cd ibis-svg-bridge
gradle --no-daemon assembleDebug
```

Путь сборки: `app/build/outputs/apk/debug/app-debug.apk`.

Границы заливки тестируются отдельно:

```sh
node --test tests/floodfill.test.cjs
```
