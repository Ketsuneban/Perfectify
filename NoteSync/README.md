# NoteSync (Windows 11)

Отдельная утилита, не меняет Android-проект Perfectify.

## Сборка
Установи .NET 8 SDK и выполни в PowerShell из корня репозитория:

```powershell
dotnet publish NoteSync/NoteSync.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o NoteSync/dist
```

Запусти `NoteSync/dist/NoteSync.exe`. Не требуются права администратора.

## Использование
1. Открой две заметки в отдельных окнах с одинаковым заголовком Windows.
2. Закрепи одно окно через PowerToys Always on Top (Win+Ctrl+T).
3. В NoteSync оставь Auto. При желании введи точный заголовок, чтобы исключить другие пары.
4. Нажми «Запустить», затем поставь курсор в любую из заметок.
5. При переходе на другой пункт NoteSync прокрутит второе окно и запросит выделение соответствующего текста. Переключение между заметками меняет направление синхронизации.
6. Для отключения восстанови окно NoteSync и нажми «Остановить».

Режимы:
- Auto: буквальные номера, а при повторениях в непрерывном списке — последовательная Markdown-нумерация.
- Literal: буквальные числа (например, 1, 5, 10).
- Markdown: нумерация по порядку, начиная с первого номера списка.
- Ненумерованный текст: логическая строка по переводу строки, не визуальный перенос.
- Если редактор публикует отрисованные элементы ListItem через UI Automation, предусмотрена попытка сопоставить их по порядку.

## Ограничения
Нужны отдельные окна и поддержка TextPattern/GetSelection/FindText/ScrollIntoView/Select в обоих редакторах. Некоторые приложения не предоставляют эти API или скрывают выделение без фокуса. В таком случае доступна только прокрутка, если её поддерживает редактор. Утилита не посылает клавиши, не меняет Always on Top и не активирует окна самостоятельно. Если поставщик UIA забирает фокус при выделении, синхронизация приостанавливается.
Не поддерживаются надёжно вложенные Markdown-списки, несколько независимых списков с одинаковыми номерами, сложные многострочные элементы, редакторы без UIA и две вкладки одного окна. Точное поведение зависит от редактора; на Windows с конкретным приложением требуется ручная проверка. Текст обрабатывается в памяти, без сетевых запросов и изменений заметок.
