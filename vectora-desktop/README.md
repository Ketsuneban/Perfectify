# Vectora SVG Desktop

**Windows 10/11 x64 · v0.5.1 preview · самостоятельный SVG-редактор для ПК**

Отдельное настольное приложение: без Android, ibisPaint X, сторонних браузеров, обязательной регистрации или доступа к интернету.

## Возможности

- Векторная кисть, ластик для основного рисунка (SVG mask), заливка связной области, пипетка, HEX и прозрачность.
- Фигуры, текст, выделение, перетаскивание, отмена и повтор действий.
- Несколько SVG поверх текущего рисунка: кнопка «Импорт SVG» и перетаскивание SVG из Проводника.
- Рамка выделения с четырьмя угловыми маркерами — пропорциональное изменение размера без превращения в PNG.
- Точные X / Y, ширина / высота и масштаб от 5 до 1000 %, центрирование размеров относительно центра.
- Панель слоёв: выбор и изменение порядка импортированных SVG; маска ластика применяется только к базовому рисунку.
- Масштаб холста колесом мыши относительно курсора, панорамирование средней кнопкой или с зажатым пробелом.
- Локальное автосохранение, SVG Save As, PNG Export через системные диалоги Windows.
- Импортированные формы, градиенты и поддерживаемые SVG-эффекты остаются векторами.

## Управление

| Клавиши | Действие |
| --- | --- |
| Колесо мыши | Масштаб холста относительно курсора |
| Пробел + перетаскивание / средняя кнопка | Перемещать холст |
| F | Вписать весь холст |
| Ctrl+O / Ctrl+Shift+O | Открыть SVG / наложить SVG |
| Ctrl+S / Ctrl+N | Сохранить SVG / новый документ |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |
| V / B / G / I / E | Выбор / кисть / заливка / пипетка / ластик |
| R / O / L / T | Прямоугольник / эллипс / линия / текст |
| Delete | Удалить выбранный объект |

## Установка Windows

GitHub Release: vectora-desktop-v0.5.1 — после успешной сборки CI.

- Vectora-SVG-Portable-0.5.1-x64.exe — запуск без установки.
- Vectora-SVG-Setup-0.5.1-x64.exe — обычная установка в Windows.

Файлы неподписанные (preview), Windows SmartScreen может предупреждать. Держи резервные копии важных работ.

## Разработка

Требуется Node.js 24 и npm для сборки. Приложение поставляется со встроенным Electron. Команды:

    cd vectora-desktop
    npm install
    npm test
    npm start
    npm run dist:win

Версии пакетов: Electron 45.4.1 и electron-builder 26.18.0. GitHub Actions на Windows собирает portable EXE и NSIS-установщик и публикует prerelease после прохождения тестов.

Код мобильной Vectora остался отдельно. Десктопная версия размещена в ветке feature/vectora-desktop репозитория Ketsuneban/Perfectify; основная ветка Perfectify и Yetta не затрагиваются.

## Ограничения

- Заливка анализирует временное растровое представление для поиска границ, но сохраняется геометрическим SVG-контуром.
- Узлы Безье, вращение рамкой и растровые слои полноценно не редактируются.
- SVG-источники и сохранённые проекты ограничены 8 МиБ; внешние ресурсы и исполняемые фрагменты SVG фильтруются.
- Импортированные SVG не стираются ластиком основного рисунка.
- Проект предварительный; не заявляется функциональная полнота Inkscape/Illustrator.
