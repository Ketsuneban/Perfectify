Yeta

Открытый мод, который переносит удачные механики Bedrock и новых версий в Minecraft Java Edition, улучшает поведение мира и мобов и исправляет неудобные расхождения оригинальной игры.

Что входит в Yeta

Улучшенные боссы и ИИ мобов, обновлённые модели и текстуры, живая погода и снег, расширенные взаимодействия с блоками и сущностями, новые возможности котлов, карт, стоек для брони и красного камня. Проект развивается открыто: код, история изменений и готовые JAR-файлы доступны каждому.

Совместимость и установка

Для запуска требуется Minecraft Java Edition 1.21.1, NeoForge 21.1.x и Java 21. Скачайте JAR из раздела «Контент» и поместите его в папку mods вашего профиля.
